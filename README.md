# QA Walkthroughs

Public, rendered QA walkthroughs and handoffs for Euro Team Outreach development projects.

The application source code lives in **private** repositories. This repo holds only the **tester-facing walkthrough pages**, so QA testers can open a live, interactive version in their browser without cloning anything. The content is intentionally non-sensitive — feature steps, fictitious seed logins, and "visit this / look for that / click here" instructions.

## How it works

- Each project gets its own subfolder (e.g. `comixdistro/`).
- A walkthrough is published as a self-contained HTML file, e.g. `comixdistro/pr-123-feature-name.html`.
- GitHub Pages serves it live at:

  ```text
  https://euroteamoutreach.github.io/qa-walkthroughs/<project>/<file>.html
  ```

- The pull request in the private app repo links to that URL, with a plain-Markdown copy of the steps as a fallback.

## Maintenance

Files here are generated by the `/walkthrough --publish` and `/qa-handoff` Claude Code skills. Update a walkthrough by re-publishing rather than editing by hand.
