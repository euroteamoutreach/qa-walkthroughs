Walkthrough

The whole point of this fix: on every admin index, the small grey record-count line used to sit outside the Turbo frame, so it froze at the first page-load value when you clicked a filter tab or searched. It now lives inside the frame and recomputes with the table. This was first spotted on the distributors page during the PR #599 walkthrough.

Part 1 — Distributors: count tracks the filter tabs new in this PR
  1. Go to .
    ✅ The list loads under the Дистриб'ютори title. Just below the title is a small grey count line, e.g. 8 дистриб'юторів, matching the number of table rows. (New layout: the count is now stacked beneath the title rather than right-aligned beside it.)
  2. Click the Мої дистриб'ютори (My distributors) tab.
    ✅ The table re-renders to just this admin's distributors (3), and the count line updates in place to 3 дистриб'ютори — no full-page reload. This is the bug fix: before this PR the count stayed at 8.
  3. Click the Видалені (Deleted) tab.
    ✅ Count updates to 0 дистриб'юторів and the empty-state message appears.
  4. Click the Усі (All) tab.
    ✅ Count returns to 8 … and the full list is back.
  5. Watch the Дистриб'ютори heading as you click between tabs.
    ✅ The title stays perfectly still — no flicker or reflow. It lives outside the swapped frame on purpose.
Part 2 — Distributors: count tracks the search box new in this PR
  1. On the Усі tab, type into the search field and press Enter.
    ✅ The table filters to matching distributors and the count line updates to match the filtered result (e.g. 1 дистриб'ютор) — the same frame, recounted.
  2. Click Clear (or empty the field and submit).
    ✅ The full list returns and the count goes back to 8 ….
