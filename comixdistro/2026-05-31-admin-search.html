What's New

Every admin list page now has a search box at the top. Type a few letters and the list narrows to matching rows without a full page reload. This rounds out the admin search work: Distributors, Users, Events, and Shipments already had it, and the Event Reports page was the last one missing — it now matches the rest.

Search is built for Ukrainian content: it ignores capitalization for Cyrillic text, so searching новий завіт and НОВИЙ ЗАВІТ return the same rows. On the Event Reports page it also looks inside the report's written narrative — text that isn't shown in the table — as well as the event title and distributor name.

Search works alongside the existing filter tabs (status / scope): a query and a tab combine, and the query stays put when you switch tabs. A Clear link (and the search box's native ✕) resets back to the full list.
