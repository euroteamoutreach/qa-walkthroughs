Walkthrough
Part 1 — Submit a report: draft allowed, submit gated on consent new in this PR
  1. Sign in as via the magic link.
    ✅ You land on the distributor dashboard, in Ukrainian.
  2. Open the Kharkiv event "Книжковий ярмарок у Харкові", then open its report for editing (the Edit report / Редагувати звіт link — the report is a draft).
    ✅ The report form opens with the existing draft narrative ("Ярмарок відбувся за планом…").
  3. Scroll to just below the Upload photos field.
    ✅ New: an unchecked consent checkbox with the text "Я маю дозвіл ділитися цими фотографіями та надаю Euro Team Outreach ліцензію на їх використання, як описано в умовах участі." — where "умовах участі" is a link.
  4. Leave the box unchecked and click Save draft / Зберегти чернетку.
    ✅ The draft saves successfully — consent is not required to save a draft. The report still shows as a draft ("Чернетка — ще не подано").
  5. Re-open Edit report. Still leaving the box unchecked, click Submit report / Подати звіт and confirm the dialog.
    ✅ Submission is blocked. The form re-renders with the error "Згода на використання фотографій обов'язкова для подання звіту" — in the red banner at the top and inline under the checkbox. The report is still a draft (nothing emailed to admins).
  6. Now check the consent box, click Submit report and confirm.
    ✅ The report submits — a success flash appears and the report now shows as Submitted ("Подано").
Part 2 — The consent link opens the new ToS clauses (uk + en) new in this PR

If the Kharkiv report is now submitted (Part 1), open the Terms directly:

  1. Click the "умовах участі" link in the checkbox label (opens /terms in a new tab).
    ✅ The Terms page opens. Inside the Фотографії (Photos) section there is a new subsection "Права на фотографії та дозволи" with two bolded clauses: "Ліцензія на використання ваших фотографій" (a perpetual license — explicitly not a transfer of ownership) and "Дозвіл від людей на ваших фотографіях" (the subject-consent warranty, including parent/guardian permission for children).
  2. Switch to English via the navbar locale switcher (or open ).
    ✅ The same subsection renders in English as "Photo Rights and Permissions", with "License to use your photos" and "Permission from the people in your photos." The checkbox label, in English, reads "I have permission to share these photos and I grant Euro Team Outreach a license to use them, as described in the terms of service."
Not browser-testable
  • The photo_consent_at timestamp value. Submission stamps it server-side; there's no UI surface for it. Covered by model tests.
  • Re-consent after rejection. Consent is contemporaneous — if an admin rejects a submitted report and the distributor edits and resubmits, the box must be checked again. Exercising it needs an admin rejection first; the rule itself is covered by model + controller tests.
  • Programmatic submission paths (seeds, rake tasks, console) are also gated by the same model validation — verified by the Tests: Seeds CI stage, not the browser.
