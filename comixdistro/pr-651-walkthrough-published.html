Setup

What changed in this PR: the distributor "Delete" action is now an honest Archive — the only operation available is a reversible soft delete, so the verb, button color, and confirm copy were all aligned to "archive" (kept & restorable, never destroyed). The irreversible admin User hard delete is deliberately left as a red, type-the-name "Delete".

  1. Start the app: → open
  2. Load seed data (admin + sample distributors): . This PR adds no migrations, env vars, or dependencies — seeds are the only prerequisite.
  3. Locale: the default locale is uk (Ukrainian), so the new copy appears in Ukrainian first. Use the language switcher (in the menu) to toggle to English — both locales were updated, so check both.
  4. Mobile-first: optionally narrow the window to 375px — the Archive button, confirm modal, and tabs should stay usable.

Walkthrough
Part 1 — Archive a distributor new in this PR
  1. Signed in as admin, go to the distributors index: (on production, the equivalent /admin/distributors path).
    ✅ The index lists active distributors with filter tabs: All · My distributors · Active events · Archived. The last tab now reads “Archived” (uk: «Архівовані») — it was “Deleted” before this PR.
  2. Click a distributor row to open its detail page (e.g. Львів Дистрибуція). Stay on the Details tab.
    ✅ At the bottom of the Details tab there is an amber Archive button (uk: «Архівувати») and a blue Edit button. Note the color: Archive is amber/yellow, not red — it is a reversible action.
  3. Click the amber Archive button.
    ✅ A confirmation modal opens reading (English): “Archive Львів Дистрибуція? The distributor will be moved to the Archived view and can be restored at any time.” (uk: «Архівувати Львів Дистрибуція? Дистриб'ютора буде переміщено до розділу «Архівовані», і його можна відновити будь-коли.»). Key checks: the confirm button is amber, there is no “type the name to confirm” box, and no “cannot be undone” warning.
  4. Click the amber confirm button.
    ✅ Redirects to the distributors index. Green flash: “Distributor was archived. You can restore it from the Archived view.” (uk: «Дистриб'ютора архівовано. Ви можете відновити його з розділу «Архівовані».»). The distributor no longer appears in the default All list.
Part 2 — Find it under “Archived” and restore new in this PR
  1. On the distributors index, click the Archived tab (uk: «Архівовані»).
    ✅ The tab is labeled “Archived” (previously “Deleted”). The distributor you just archived is listed here, with a green Restore button on its row.
  2. Click Restore on that row (confirm “Restore this distributor?” if prompted).
    ✅ Flash: “Distributor was restored.” The distributor returns to the active list and disappears from Archived.
  3. (Optional) Open the archived distributor’s show page before restoring.
    ✅ An amber banner reads “This distributor has been archived and is read-only.” with a Restore button there too.
  4. (Optional) Restore the only archived distributor, then revisit the Archived tab.
    ✅ Empty state reads “No archived distributors.” (uk: «Немає архівованих дистриб'юторів.»).
