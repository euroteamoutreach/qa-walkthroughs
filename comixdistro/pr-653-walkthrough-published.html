Setup

This PR replaces the free-form Event type text field with a curated dropdown of eight types, plus a “Other” option that reveals a free-form “please specify” field. It adds a migration (a new event_type_other column) and updates seed data to use the new enum keys.

  1. Apply the new column and refresh seed data:
  2. Start the app: →

Locale. The default locale is Ukrainian (uk); seed users are set to uk, so the dropdown labels render in Ukrainian. English labels are given in parentheses below for reference.

Mobile-first. PR #653's test plan left one box unchecked: the 375px-wide check of the select and the conditional free-form field. Part 1 calls out where to verify it.

Walkthrough
Part 1 — Distributor picks an event type from the new dropdown new in this PR
  1. Sign in as via the magic link.
    ✅ You land on the distributor dashboard.
  2. Open Events and click Нова подія (New event).
    ✅ The event form opens. Тип події (Event type) is now a dropdown showing the prompt Оберіть тип події (Select an event type) — no longer a free-text box.
  3. Open the dropdown.
    ✅ Eight options in Ukrainian: Дитячий табір (Kids camp), Вулична роздача (Street outreach), Лікарня (Hospital), Дитячий будинок (Orphanage), Церковна служба (Church service), Виїзд / реколекції (Retreat), Концерт (Concert), Інше (Other).
  4. Select a normal type, e.g. Вулична роздача (Street outreach).
    ✅ No extra field appears below the dropdown.
  5. Now select Інше (Other).
    ✅ A free-form field labelled Будь ласка, уточніть (Please specify) appears just below the dropdown.
  6. Type something in it (e.g. Книжкова виставка), then switch the dropdown back to Вулична роздача.
    ✅ The free-form field hides and its text is cleared — switching back to “Інше” shows it empty again.
  7. 375px check. Narrow the browser to 375px wide (or device toolbar → iPhone SE). Re-open the dropdown and toggle to “Інше”.
    ✅ The select and the revealed free-form field stack cleanly inside the form grid — no overflow or clipped controls.
  8. Set the type to Інше, type Книжкова виставка, fill the remaining required fields (title, dates, books, shipping, terms checkbox), then click Подати на розгляд (Submit for review).
    ✅ The event saves and its show page lists Тип події: Книжкова виставка — your free-form text, never a raw key like other.
Part 2 — Required-field validation new in this PR

Not browser-testable
🧹
Server-side clearing of the free-form text. The dropdown's Stimulus controller clears the “please specify” input in the browser, but the model also nils event_type_other on save whenever the type isn't “Other” (a before_validation callback). That server-side guarantee is covered by model tests.
🗄️
Migration backfill. The migration moves any pre-existing non-enum event_type value into event_type_other and sets the type to “Other”. This is a one-time data migration with no UI surface (and pre-launch data is throwaway), so it's verified by reasoning and the migration itself, not the browser.
