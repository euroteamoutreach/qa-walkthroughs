Setup

This PR turns every in-page "Back" affordance into an honest, named link: footer links now read ← <destination> and always go there. On the tabbed admin cards, the redundant "back to primary tab" buttons are gone — you switch panels with the tabs themselves, and each card has exactly one footer up-link. The whole point is the label and where it lands, so this walkthrough is mostly "read the link, click it, confirm where you land" — in both languages.

  1. Start the app: → open
  2. No new migrations, env vars, or dependencies. If your seed data is stale, refresh it:
  3. Locale: the app defaults to Ukrainian, so you'll first see ← Події, ← Відправлення, etc. A language switcher lives in the top-right nav (and the mobile menu) — toggle it to English to see ← Events, ← Shipments. Verifying both is the heart of this PR.
  4. Mobile-first: worth a quick pass at 375px — the footer links sit in a wrapping flex row.

Part 2 — Admin: tabbed cards are clean — one up-link, no redundant back buttons new in this PR

The admin event / shipment / distributor pages are tabbed. Secondary panels used to end with a "back to primary tab" button; once named, it duplicated the primary tab (two "Event" controls doing the same thing). Those buttons are now removed — the tab itself does the job.

  1. As admin, open an event. Click the Distributor tab, then the Report tab. Scroll to the bottom of the Report panel.
    ✅ No footer button at the bottom of the secondary panel — no "Back", no second "Event". The panel just ends.
  2. Click the Event tab in the tab bar to return to the primary view.
    ✅ Switches back to the Event panel, which has the single ← Events up-link in its footer. There's exactly one navigation affordance, and its label names where it goes.
  3. Same shape on the admin shipment and distributor cards: secondary tabs (e.g. Team / Invites / History) have no footer button; only the primary tab carries the ← <index> link.
    ✅ Confirm this reads cleaner to you than the duplicate-label version did.
